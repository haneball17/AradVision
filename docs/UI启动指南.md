# 经典 PyQt5 控制面板启动指南

## 适用范围

本文档只描述当前保留的经典控制面板。

以下内容已暂停，不再适用本指南：

- 训练数据资产管理工作台
- 时间线采集/筛选/预标注界面
- `scripts/test_timeline_ui.py`

## 安装依赖

```bash
pip install -r requirements-full.txt
```

至少需要：

- `PyQt5`
- `numpy`
- `opencv-python`
- `mss`

## 启动方式

推荐直接通过主程序启动：

```bash
python main.py --ui -c configs/config.yaml
```

如果只想验证经典窗口能否正常创建，也可以使用：

```bash
python scripts/test_pyqt_ui.py
```

## 当前定位

经典 UI 当前主要承担以下用途：

- 运行状态观察
- 视频预览与日志查看
- 参数调试入口

它不是训练数据采集工具，也不是当前资产流程的主入口。

## 使用建议

1. 没有真实游戏环境时，优先使用 Mock 配置启动。
2. 需要真实输入时，先确认窗口焦点、输入依赖和紧急停止功能。
3. 把 UI 视为辅助面板，不要把它当作当前版本的数据工作台。

## 故障排查

### 无法导入 PyQt5

```bash
pip install PyQt5
```

### 启动后无实时数据

- 检查当前是否使用 Mock 配置
- 检查捕获与输入依赖是否安装完整
- 检查目标窗口标题是否与配置一致

### 需要训练数据采集流程

请不要回到旧工作台路径，改用：

1. 外部录屏工具采集视频流
2. 仓库外抽帧/筛选
3. 按导入规范引入训练数据

详见 `docs/自动化主线收敛与外部资产导入/自动化主线收敛与外部资产导入.md`。
