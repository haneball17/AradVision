# PyQt5 控制面板启动指南

## 安装依赖

在 Windows 环境中安装 PyQt5：

```bash
pip install PyQt5
```

或者使用 requirements.txt：

```bash
pip install -r requirements.txt
```

## 启动方式

### 方式 1: 使用测试脚本（推荐）

```bash
python scripts/test_pyqt_ui.py
```

### 方式 2: 直接运行主程序

```bash
python main.py --ui
```

## 功能说明

### 标签页 1: 实时监控

- **视频预览**: 显示实时捕获的游戏画面
- **状态面板**:
  - 性能指标（FPS、延迟、帧数、运行时长）
  - 决策状态（当前状态、持续时长、状态历史）
  - 检测信息（英雄、怪物、物品、门、房间状态）
  - 快速控制（启动、暂停、停止按钮）

### 标签页 2: 参数配置

#### 捕获设置
- **目标 FPS**: 10-60（滑块调节）
- **显示器选择**: 主显示器/显示器 2/显示器 3
- **检测模式**: Mock（模拟）/ YOLO（真实）

#### 战斗配置
- **Y 轴对齐容差**: 5-50 像素（滑块调节）
- **攻击范围**: 50-200 像素（滑块调节）
- **技能优先级**: 拖拽排序的技能列表
  - 可添加新技能（"添加技能"按钮）
  - 可删除选中技能（"删除选中"按钮）
  - 拖拽调整技能释放顺序

#### 高级设置
- **置信度阈值**: 0.1-0.9（滑块调节）
- **房间清空超时**: 1-10 秒（滑块调节）

#### 日志配置
- **日志级别**: DEBUG/INFO/WARNING/ERROR
- **保存日志到文件**: 复选框

#### 界面设置
- **主题**: 暗色（默认）/ 明亮
- **开机自动启动**: 复选框

#### 配置管理
- **保存配置**: 保存到 YAML 文件
- **加载配置**: 从 YAML 文件加载
- **导出配置**: 导出配置文件
- **导入配置**: 导入配置文件
- **重置默认**: 恢复所有参数为默认值

#### 应用设置
- **应用所有设置**: 应用当前修改的参数
- **恢复上次设置**: 恢复到上次保存的设置

### 标签页 3: 系统日志

#### 日志过滤
- **日志级别**: 全部/DEBUG/INFO/WARNING/ERROR
- **搜索**: 输入关键词过滤日志
- **自动滚动到底部**: 复选框
- **清除日志**: 清空所有显示的日志

#### 日志内容
- 实时显示系统日志
- 等宽字体（Consolas / Courier New）
- 颜色编码：
  - DEBUG: 灰色
  - INFO: 蓝色
  - WARNING: 橙色
  - ERROR: 红色

#### 日志统计
- 总计: 显示总日志条数
- DEBUG: DEBUG 级别日志数量
- INFO: INFO 级别日志数量
- WARNING: WARNING 级别日志数量
- ERROR: ERROR 级别日志数量

## 快捷键

- **F5**: 启动系统
- **F12**: 停止系统（紧急停止）
- **Ctrl+S**: 保存配置

## 主题切换

通过菜单栏 `视图` → `切换主题` 切换暗色/亮色主题。

默认使用暗色主题，适合长时间使用。

## 注意事项

1. **Mock 模式**: 在没有游戏环境时使用 Mock 模式测试 UI
2. **真实模式**: 需要安装 YOLOv8 模型和完整依赖
3. **配置持久化**: 参数修改后需要点击"应用所有设置"才会生效
4. **日志自动清理**: 日志面板最多保留 1000 条日志
5. **紧急停止**: 随时按 F12 键可紧急停止系统

## 故障排除

### 问题: 无法启动 PyQt5

**解决**: 确保已安装 PyQt5

```bash
pip install PyQt5
```

### 问题: 视频预览显示黑屏

**原因**: 系统未启动或未连接到游戏窗口

**解决**:
1. 点击"启动"按钮启动系统
2. 确保游戏窗口在前台
3. 检查参数配置中的显示器选择是否正确

### 问题: 参数修改后无效

**原因**: 参数修改后需要点击"应用所有设置"

**解决**: 点击参数配置页面底部的"应用所有设置"按钮

### 问题: 技能列表无法拖拽

**解决**:
1. 确保使用的是 PyQt5（不是 PyQt4）
2. 重启 UI 尝试
