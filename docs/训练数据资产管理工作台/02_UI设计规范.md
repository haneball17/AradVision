# 训练数据资产管理工作台：UI 设计规范

**版本**：v2.2  
**日期**：2026-02-26  
**角色**：架构与逻辑工程师（yangmq17）

## 1. 设计目标
1. 风格：现代、浅色、扁平化、SaaS 工具风。  
2. 主任务优先：让“实时预览 + 筛选操作 + 导出参数”成为视觉中心。  
3. 高 DPI 稳定：Windows 125%/150% 缩放下不出现重叠与挤压。

## 2. 信息架构
采用流程导航：
```text
[采集] -> [筛选] -> [预标注] -> [导出]
```

主界面分区：
1. 顶部：任务导航与全局操作。  
2. 中央主区：实时预览/缩略图网格/时间线。  
3. 右侧：参数与操作面板。  
4. 可折叠辅助区：会话列表、系统日志（默认折叠）。

## 3. 默认折叠策略（最佳实践）
1. `会话列表` 默认折叠，按需展开。  
2. `系统日志` 默认折叠，发生错误时自动高亮并提示展开。  
3. 使用 `QDockWidget` 或等价折叠容器，支持停靠、展开、隐藏。  
4. 折叠状态通过 `QSettings` 持久化，重启后恢复。

说明：Qt 官方支持通过 `QMainWindow::saveState/restoreState` 持久化停靠布局，适合作为默认实现路径。

## 4. 布局与响应式规范
1. 采用 8pt 间距体系：4/8/12/16/24/32。  
2. 页面外边距 24，卡片内边距 16，模块间距 24。  
3. 中央区使用 `QSplitter`，设置最小尺寸与拉伸因子，避免挤压重叠。  
4. 关键最小尺寸：
   - 实时预览区最小高度：260  
   - 时间线区最小高度：140  
   - 右侧参数区最小宽度：300  
5. 当窗口宽度不足（如 <1360）时自动触发降级布局：
   - 优先折叠会话列表。  
   - 次优折叠系统日志。  
   - 最后将时间线切为可展开子面板。

## 5. 视觉 Token（浅色主题）
主色与语义色：
1. `primary-500`：`#2F6BFF`  
2. `primary-600`：`#2459D8`（hover）  
3. `danger-500`：`#F04438`  
4. `success-500`：`#12B76A`

背景与文字：
1. `bg-app`：`#F5F7FB`  
2. `bg-surface`：`#FFFFFF`  
3. `bg-subtle`：`#EEF2F8`  
4. `text-primary`：`#1F2430`  
5. `text-secondary`：`#5B6475`  
6. `border`：`#E7ECF3`

## 6. 字体与层级
字体栈：
```text
"Segoe UI", "PingFang SC", "Microsoft YaHei UI", sans-serif
```

字号层级：
1. 页面标题：20/600  
2. 模块标题：16/600  
3. 区块标题：14/600  
4. 正文：13/400  
5. 辅助文本：12/400

## 7. 组件交互规范
按钮：
1. 高度 34，圆角 8。  
2. 默认、hover、pressed、disabled 必须有清晰状态。  
3. 破坏性操作仅使用 `danger` 语义按钮。

输入框与下拉：
1. 高度 32，圆角 6。  
2. focus 使用高对比外轮廓（2px 主色）。

缩略图卡片：
1. 支持角标显示：标记状态、质量分数、目标数。  
2. 选中态使用浅主色底，不用重边框闪烁。

## 8. 键盘与可用性
默认快捷键：
1. `1` 标记 star  
2. `2` 标记 reject  
3. `3` 标记 review  
4. `0` 清除标记  
5. `Ctrl+F` 聚焦筛选  
6. `Ctrl+E` 快速导出

## 9. QSS 落地规范
1. 全局一次性加载 QSS，不在控件层分散 `setStyleSheet`。  
2. 推荐结构：
```text
ui/theme/
  tokens.light.qss
  components.qss
  layout.qss
  pages/capture.qss
  pages/curation.qss
```
3. 使用 `objectName` 或 `property` 做变体选择器，避免深层级选择器链。  
4. 用留白分区替代大量边框。

## 10. 性能策略
1. 列表/网格使用虚拟化视图（`QListView/QTableView + delegate`）。  
2. 缩略图懒加载：按可视区 + 前后缓冲窗口加载。  
3. 图像解码与缩放放到后台线程，主线程只做展示更新。  
4. 日志面板限制渲染行数并支持按级别过滤。

## 11. 验收标准
1. 125%/150% 缩放均无控件重叠。  
2. 默认折叠策略生效，且状态可持久化恢复。  
3. 1 万张样本下滚动和筛选保持可用，无明显卡顿。  
4. 样式集中管理，无页面私有散乱样式。
