# 训练数据资产管理工作台：数据筛选模块设计

**版本**：v2.2  
**日期**：2026-02-26  
**角色**：架构与逻辑工程师（yangmq17）

## 1. 模块目标
1. 让用户在大规模样本中快速定位高价值训练样本。  
2. 提供“筛选 + 标记 + 子集保存”的闭环，而不是临时手工拷贝。  
3. 保障筛选结果可复现、可追溯。

## 2. 输入输出
输入：
1. `samples.jsonl`  
2. `session_manifest.json`  
3. 可选：预标注统计摘要

输出：
1. 更新后的样本标记状态（写回索引或 sidecar）。  
2. `selection_manifest.json`（保存筛选条件与样本集合）。  
3. 筛选统计报告（场景分布、标记分布、质量分布）。

## 3. 筛选模型
### 3.1 筛选维度
1. 时间：`timestamp_ms`、会话区间。  
2. 场景：`combat/navigate/loot/boss/other`。  
3. 质量：模糊分、重复分、是否过滤。  
4. 人工状态：`none/star/reject/review`。  
5. 伪标签摘要：目标数量、平均置信度、类别存在性。

### 3.2 标记语义
1. `star`：优先纳入训练集。  
2. `reject`：明确剔除。  
3. `review`：进入复核队列。  
4. `none`：未决样本。

## 4. 时间区间语义（强制约定）
1. 区间 A/B 默认采用闭区间 `[A, B]`。  
2. A 或 B 为空时：
   - A 为空：使用最小时间。  
   - B 为空：使用最大时间。  
3. 若 A > B，UI 阻止提交并提示错误。

## 5. 时间抽样语义（强制约定）
输入：区间 `[A, B]`，采样频率 `f`（例如 1s）。  
算法：按时间桶抽样 + 最近帧匹配。
1. 生成时间桶：`A, A+f, A+2f ... <= B`。  
2. 每个桶选择“时间差最小”的样本。  
3. 若桶内无样本：
   - 默认跳过并计入 `missed_buckets`。  
   - 可选模式：允许向后找最近样本（需在 manifest 记录）。
4. 并列规则（确定性）：
   - 若两帧到桶中心的时间差相同，优先选择 `timestamp_ms` 更小的样本。  
   - 若时间戳也相同，优先选择 `sample_id` 字典序更小的样本。

## 6. 视图与交互
1. 主视图：缩略图网格（默认）。  
2. 辅视图：时间线（用于定位突变片段）。  
3. 快捷键：`1/2/3/0` 标记，`Ctrl+F` 筛选，`Ctrl+S` 保存视图。  
4. 批量动作：对当前筛选结果批量标记、批量取消。

## 7. 选择集保存与重放
`selection_manifest.json` 必填字段：
```json
{
  "schema_version": "v2.2",
  "selection_id": "sel_20260226_130500",
  "created_at": "2026-02-26T13:05:00Z",
  "source_sessions": ["ui_capture_20260226_120000_dnf_taiwan"],
  "range": {"start_ms": 1772088000000, "end_ms": 1772088600000, "inclusive": true},
  "sampling": {
    "mode": "bucket_nearest",
    "frequency_sec": 1,
    "missing_bucket_policy": "skip",
    "tie_breaker": "timestamp_then_sample_id",
    "missed_buckets": 12
  },
  "filters": {"scene_in": ["combat"], "manual_flag_not_in": ["reject"], "blur_gte": 60},
  "result": {"total": 540, "star": 320, "review": 110, "none": 110}
}
```

## 8. 性能策略
1. 样本索引内存化，图片按需加载。  
2. 缩略图异步解码，主线程只处理 UI 刷新。  
3. 支持分页与虚拟滚动，避免一次性创建大量控件。  
4. 筛选表达式执行时间超过阈值时输出性能日志。

## 9. 质量与一致性风险控制
1. 误标控制：支持撤销/重做。  
2. 标签污染控制：长时间单场景时弹提醒。  
3. 一致性控制：标记操作写审计日志并持久化。

## 10. 测试与验收
1. 单元测试：区间解析、抽样算法、筛选表达式。  
2. 集成测试：1 万样本下筛选和标记流程稳定。  
3. 验收标准：
   - 闭区间语义稳定，重放结果一致。  
   - `selection_manifest.json` 可用于复现同一结果。  
   - 交互性能满足可用要求（滚动与筛选无明显卡顿）。
