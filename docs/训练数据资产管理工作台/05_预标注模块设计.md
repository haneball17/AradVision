# 训练数据资产管理工作台：预标注模块设计

**版本**：v2.2  
**日期**：2026-02-26  
**角色**：架构与逻辑工程师（yangmq17）

## 1. 模块目标
1. 对筛选后的样本批量生成伪标签，降低人工标注成本。  
2. 支持多模型版本并行比较，保证可追溯。  
3. 形成“预标注 -> 人工复核 -> 回写状态”的闭环。

## 2. 输入与输出
输入：
1. 样本集合（来源：flag/filter/manual_selection）。  
2. 模型配置（权重路径、类别、阈值）。  
3. 任务参数（批大小、设备、是否覆盖旧结果）。

输出：
1. 伪标签文件（YOLO txt 或中间 JSON）。  
2. `pseudo_task_manifest.json`。  
3. 质量统计（置信度分层、类别分布、失败样本列表）。

## 3. 首版类别范围
首版伪标签只覆盖：
1. `monster`  
2. `hero`  
3. `gate`

说明：先保证稳定收益，减少低质量伪标签污染训练集。

## 4. 任务编排流程
```text
创建任务 -> 冻结输入集合 -> 加载模型 -> 批量推理 -> 写标签 -> 统计质量 -> 任务收尾
```

任务状态机：
```text
created -> running -> completed
                    -> failed
                    -> canceled
```

## 5. 阈值策略
推荐三段式：
1. 高置信 `>= 0.80`：默认直接入复核快通道。  
2. 中置信 `0.60~0.79`：需人工重点复核。  
3. 低置信 `< 0.60`：默认不入训练集。

阈值配置按类别可独立设置，且任务内固化到 manifest。

## 6. 版本化规范
目录结构：
```text
labels_pseudo/
  v1.0/
    labels/
    pseudo_task_manifest.json
  v1.1/
    labels/
    pseudo_task_manifest.json
```

关键规则：
1. 新版本默认不覆盖旧版本。  
2. 覆盖模式仅允许同版本重跑，且必须记录 `overwritten_from_run_id`。  
3. 任务输入集合 hash 固化，保证可复算。

## 7. `pseudo_task_manifest.json` 契约
```json
{
  "schema_version": "v2.2",
  "task_id": "pseudo_20260226_140000",
  "version": "v1.0",

  "model": {"name": "yolov8n", "weights": "runs/train/exp1/best.pt"},
  "classes": ["monster", "hero", "gate"],
  "thresholds": {"monster": 0.6, "hero": 0.65, "gate": 0.55},

  "result": {"predicted_samples": 510, "failed_samples": 30, "boxes_total": 1480},
  "quality": {"high_conf": 900, "mid_conf": 430, "low_conf": 150}
}
```

## 8. 复核闭环
1. 预标注结果进入复核队列。  
2. 复核后回写样本状态与标签修订记录。  
3. 对低置信和冲突样本优先复核。  
4. 复核通过后可将样本推进到 `reviewed/train_ready`。

## 9. 异常处理
1. 模型加载失败：任务直接失败并输出诊断。  
2. 单样本推理失败：写入失败列表，任务可继续。  
3. 标签写入失败：重试后仍失败则记为失败样本。  
4. 中断恢复：支持从未完成批次续跑（基于任务进度记录）。

## 10. 测试与验收
1. 单元测试：阈值分类、任务状态流转、manifest 序列化。  
2. 集成测试：固定输入集多次运行结果一致。  
3. 验收标准：
   - 任务版本可追溯。  
   - 失败样本可定位可重试。  
   - 复核后状态回写正确。
