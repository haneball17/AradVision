# 训练数据资产管理工作台：数据文件结构说明

**版本**：v2.2  
**日期**：2026-02-26  
**角色**：架构与逻辑工程师（yangmq17）

## 1. 目录总览
```text
assets/
  images/
    raw/
      <session_id>/
        images/
          frame_000000.jpg
          ...
        session_manifest.json
        samples.jsonl
    selected/
      <selection_id>/
        selection_manifest.json
        sample_ids.txt
    datasets/
      <export_id>/
        images/train|val|test/
        labels/train|val|test/
        data.yaml
        selection_manifest.json
        validation_report.json
    labels_pseudo/
      <pseudo_version>/
        labels/
        pseudo_task_manifest.json
```

## 2. 命名规范
1. `session_id`：`ui_capture_YYYYmmdd_HHMMSS_<safe_window_title>`  
2. `selection_id`：`sel_YYYYmmdd_HHMMSS`  
3. `export_id`：`export_YYYYmmdd_HHMMSS`  
4. `pseudo_version`：`v{major}.{minor}`  
5. 样本文件：`frame_{index:06d}.jpg`

## 3. 文件职责
1. `session_manifest.json`：采集会话摘要、配置快照、统计信息。  
2. `samples.jsonl`：样本事实表，后续筛选与导出的唯一索引基线。  
3. `selection_manifest.json`：筛选与导出复现凭证。  
4. `pseudo_task_manifest.json`：预标注任务可追溯记录。  
5. `validation_report.json`：训练前校验门禁报告。

## 4. `samples.jsonl` 字段说明
必填字段：
1. `sample_id`：字符串，样本唯一标识。  
2. `timestamp_ms`：整数，UTC 毫秒时间。  
3. `image_path`：字符串，相对会话根目录路径。  
4. `scene`：字符串，场景标签。  
5. `state`：字符串，样本状态。  
6. `filtered`：布尔。  
7. `filter_reason`：字符串。  
8. `quality.blur_score`：浮点。  
9. `quality.dup_mse_to_prev`：浮点。  
10. `manual_flag`：字符串，`none|star|reject|review`。

推荐字段：
1. `window_state`：`foreground|background|minimized`。  
2. `actual_interval_ms`：实际采样间隔。  
3. `pseudo_summary`：伪标签摘要（目标数、均值置信度）。

## 5. 生命周期与目录映射
1. `raw/`：采集源数据，保持不可变原则。  
2. `selected/`：筛选结果集合，表达“逻辑子集”，非训练最终产物。  
3. `labels_pseudo/`：预标注版本仓。  
4. `datasets/`：训练可用导出包，带完整校验与清单。

## 6. 写入规范
1. JSON 使用 UTF-8，换行 `\n`。  
2. `samples.jsonl` 每行一条合法 JSON，不允许跨行对象。  
3. 所有 manifest 必须包含 `version` 与 `created_at`。  
4. 写入采用“先临时后提交”策略，避免半写入文件。

## 7. 清理与归档
1. 默认保留最近 N 个会话（建议 N=5，可配置）。  
2. 可选清理策略：
   - 删除 `filtered=true` 且未被选中的样本文件。  
   - 清理失败的临时导出目录。  
3. 清理动作必须先输出预览清单，支持 dry-run。

## 8. 索引与检索建议
1. 以 `samples.jsonl` 构建内存索引，加速筛选与统计。  
2. 可引入轻量索引文件（如 `samples.index.json`）记录偏移。  
3. 跨会话检索按 `session_id + timestamp_ms` 排序合并。

## 9. 示例：最小可训练导出包
```text
assets/images/datasets/export_20260226_150000/
  images/train/000001.jpg
  labels/train/000001.txt
  images/val/000101.jpg
  labels/val/000101.txt
  data.yaml
  selection_manifest.json
  validation_report.json
```

## 10. 兼容性约束
1. 路径分隔符统一在 manifest 中使用 `/`。  
2. 文件名仅允许字母、数字、下划线、短横线。  
3. Windows 环境下目录总长度建议 < 240 字符。  
4. 如果启用 DVC，仅对 `datasets/` 与关键 manifest 做版本追踪。
