## 2. 关键实现说明

1. `auto` 策略：Windows 优先尝试 WGC，失败自动降级 MSS；非 Windows 直接 MSS。  
2. `wgc` 策略：默认允许降级 MSS（可通过 `allow_fallback=False` 禁止）。  
3. 当 `use_mock=true` 时仍优先走 Mock 捕获，不走真实后端链路。  
4. WGC 运行依赖第三方库，若依赖缺失不会中断主流程，会触发降级。
