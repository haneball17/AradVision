# AradVision 开发计划与里程碑

**状态**: 主线收敛中
**最后更新**: 2026-03-12

## 当前决策

- 自动化运行链路是当前唯一主线。
- “训练数据资产管理工作台”暂停，不再进入当前里程碑。
- 训练数据获取改为“外部工具录制视频流 + 仓库仅维护导入规范”。
- `dev` 是主开发集成线，`main` 是稳定线。

## 当前阶段目标

### 阶段 1：主线收敛

- 清理时间线工作台相关入口、脚本和专题文档
- 新增归档说明与外部资产导入规范
- 更新 README、快速启动、路线图和现状文档
- 保持现有自动化主链路代码可编译、可继续开发

### 阶段 2：运行链路补强

- 继续完善 `CaptureEngine -> Detector -> WorldModel -> BotFSM -> InputDriver`
- 收敛真实输入与窗口焦点管理问题
- 完善主循环和 UI 线程的稳定性验证
- 补齐针对主链路的单测和集成测试

### 阶段 3：真实感知接入

- 实现真实 YOLO 检测器
- 引入基于外部视频/抽帧结果的训练数据流
- 明确模型文件与训练产物的本地管理方式
- 在保留 Mock 回退的前提下打通真实检测配置

## 里程碑

| 里程碑 | 目标 | 完成判定 |
|--------|------|----------|
| M1 | 主线聚焦完成 | 主仓不再宣传工作台；归档策略落地；外部导入规范成文 |
| M2 | 运行链路稳定 | 控制台主循环和经典 UI 基础联调稳定，关键语法/检查通过 |
| M3 | 感知链路可替换 | 配置可在 Mock 与真实检测间切换，模型接入路径明确 |
| M4 | 训练闭环明确 | 外部采集、抽帧、导入、训练、回灌配置形成稳定流程 |

## 当前优先级

### P0

- 自动化主链路稳定性
- 真实检测器接入方案
- 外部资产导入规范

### P1

- 经典 UI 的监控与调试价值
- 状态读取、房间导航、自动拾取
- 测试与环境脚本补强

### P2

- 视觉表现优化
- 非核心 UI 体验增强
- 暂停方向的重新评估

## 不再纳入当前里程碑的事项

- 仓库内训练数据工作台
- 时间线采集/筛选/预标注桌面流程
- 工作台风格和布局迭代

如需恢复该方向，只能从归档分支 `docs/workbench-v2-refactor` 或标签
`archive/workbench-v2-freeze-2026-03` 重新评估后单独开启。
