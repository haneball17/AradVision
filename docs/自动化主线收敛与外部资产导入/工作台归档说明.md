# 工作台归档说明

- `ui/timeline_window.py`
- `scripts/test_timeline_ui.py`
- 时间线工作台专用 widgets
- 工作台专题设计文档

## 归档位置

- 分支：`docs/workbench-v2-refactor`

## 归档原因

1. 当前训练资产获取方案已改为外部视频流采集
2. 仓库内数据工作台不再是近期交付重点
3. 两条主线同时推进会持续分散主链路开发资源

## 当前主仓策略

- 主仓文档必须明确标注工作台已暂停
- 主仓不再保留工作台入口与专题文件
- 主仓只维护自动化主链路和外部资产导入规范

## 如需恢复

恢复流程固定为：

1. 从归档标签或归档分支新开分支
2. 重新审查当时的 UI、数据格式和目标范围
3. 明确新需求后再决定是否回到主仓

禁止直接把旧工作台提交整段合并回 `dev`。
