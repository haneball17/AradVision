# 文档归档与架构收口

## 1. 目标

本次整理只做两件事：

- 清理 `docs/` 顶层噪音，把历史规划、阶段记录和非主线专题迁入归档区。
- 把 README 和主线文档收口到当前代码事实，避免继续用早期“大而全”文档描述现在的仓库。

## 2. 保留原则

- 保留与当前运行链路直接相关的文档：架构、测试、UI 启动、WGC 改造、固定路线 MVP。
- 保留当前专题目录中的近期实施记录与测试记录。
- 不删除历史，而是迁入 `docs/archive/` 保留追溯能力。

## 3. 架构口径调整

- 当前主线改为围绕固定路线 MVP 展开，而不是泛化为通用 YOLO 自动化平台。
- UI 明确区分为默认控制面板和辅助时间线工作台。
- `docs/README.md` 成为新的统一入口，`docs/archive/README.md` 说明归档分类。

## 4. 结果

- `docs/` 顶层只保留当前主线文档与当前专题。
- README 文档索引改成当前可用文档集合。
- 历史资料仍保留在仓库内，但不再干扰主线阅读路径。
