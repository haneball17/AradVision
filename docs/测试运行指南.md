## 1. 环境准备

### 1.1 确认 Python 版本

```bash
# 检查 Python 版本
python --version

# 或
python3 --version
```

**期望输出**：
```

```

如果版本 < 3.10，请先升级 Python。

---

### 1.2 克隆/更新代码

```bash

cd AradVision

git pull origin dev
```

**期望输出**：

### 1.3 创建虚拟环境

```bash

```

## 6. 常见问题

### 6.1 问题：ImportError: No module named 'xxx'

**错误示例**：
```
ImportError: No module named 'loguru'
```

**解决方法**：
```bash
# 安装缺失的包
pip install loguru

# 或重新安装所有依赖
pip install -r requirements.txt --force-reinstall
```

---

### 6.2 问题：ModuleNotFoundError: No module named 'core'

**错误示例**：
```
ModuleNotFoundError: No module named 'core'
```

**解决方法**：
```bash
# 确保在项目根目录运行
cd /path/to/AradVision

# 或添加项目路径到 PYTHONPATH
export PYTHONPATH="${PYTHONPATH}:."
# Windows
set PYTHONPATH=%PYTHONPATH%;.
```

---

### 6.3 问题：pytest 命令不存在

**错误示例**：
```
bash: pytest: command not found
```

**解决方法**：
```bash
# 使用 Python 模块方式运行
python -m pytest -v

# 或安装 pytest
pip install pytest
```

---

### 6.4 问题：tests 目录下无法导入模块

**错误示例**：
```
from core.types import GameObject
ModuleNotFoundError: No module named 'core'
```

**解决方法**：
检查 `tests/conftest.py` 是否包含以下内容：

```python
import sys
from pathlib import Path

# 添加项目根目录到 Python 路径
project_root = Path(__file__).parent.parent
sys.path.insert(0, str(project_root))
```

如果没有，添加上述代码。

---

### 6.5 问题：编码错误

**错误示例**：
```
UnicodeDecodeError: 'gbk' codec can't decode byte 0xff...
```

**解决方法**：
```bash
# Windows 设置环境变量
set PYTHONIOENCODING=utf-8

# 或在代码中指定编码
open(file, 'r', encoding='utf-8')
```

---

### 6.6 问题：虚拟环境激活失败

**错误示例**：
```
.venv/Scripts/activate: Permission denied
```

**解决方法**：
```bash
# Linux/Mac
chmod +x .venv/bin/activate

# 或使用 bash 直接运行
source .venv/bin/activate
```
