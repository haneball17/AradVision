## 设计决策

### 为什么选择 PyQt5 而不是 Web 界面？

1. **专业游戏工具定位**: 类似 OBS、WeGame 等专业工具
2. **性能优势**: 原生 GUI，无浏览器开销
3. **系统集成**: 更好的窗口管理、快捷键支持
4. **长期维护**: 桌面应用更适合游戏辅助工具
5. **用户体验**: 响应更快，操作更流畅

### 为什么使用"点击应用"而不是实时生效？

1. **防止误操作**: 用户可以调整多个参数后统一确认
2. **批量修改**: 支持配置文件的导入/导出
3. **撤销机制**: 可以恢复到上次保存的设置
4. **明确反馈**: 应用成功/失败有明确的提示对话框

### 为什么默认使用暗色主题？

1. **玩家偏好**: 游戏玩家普遍偏好暗色界面
2. **长时间使用**: 减少眼睛疲劳
3. **专注体验**: 突出游戏画面，减少界面干扰

## 已知限制

1. **高 DPI 支持**: 需要启用高 DPI 缩放才能在 4K 屏幕上正常显示
2. **Linux 兼容性**: UI 主要为 Windows 设计，Linux 上可能需要额外配置
3. **日志格式**: 日志面板的 HTML 导出功能依赖于简单解析器，复杂 HTML 可能无法正确处理
