# 工作总结：P0-P1 主链路与契约修复

- 日期：2026-02-18
- 角色：架构与逻辑工程师（Codex）
- 范围：`main.py`、`core/config.py`、`input/input_driver.py`、`logic/bot_fsm.py`、`ui/threads/engine_thread.py`、`tests/test_input_driver.py`

## 本次目标

按修复清单优先完成 P0-P1 问题，重点解决主循环链路漂移、配置失效、输入契约不一致、UI 线程配置/FPS 错误和重复定义问题。

## 关键修复项

1. 主循环收敛为单一决策链路
- 位置：`main.py`
- 调整：改为直接执行 `BotFSM` 输出 `Command`，移除主循环二次战斗/寻路决策。
- 价值：避免 `LOOT/NAVIGATE/RECOVERY` 指令被覆盖或丢失。

2. 修复无效方法调用
- 位置：`main.py`
- 调整：移除对不存在 `decide_attack` 的依赖（主循环不再进行二次 combat 调度）。

3. 修复紧急停止线程启动时机
- 位置：`main.py`
- 调整：先设置 `is_running=True` 再启动 kill switch 监听。
- 价值：避免监听线程因条件不成立立即退出。

4. 修复 `capture.use_mock` 配置失效
- 位置：`core/config.py`
- 调整：在 `CaptureConfig` 解析和默认配置生成时写入 `use_mock`。

5. 修复 `--no-mock` 优先级
- 位置：`main.py`
- 调整：`use_mock` 改为三态（`None/True/False`），命令行显式值优先，未显式传入时按配置文件。

6. 打通输入驱动注入（mock/real）
- 位置：`main.py`、`ui/threads/engine_thread.py`
- 调整：按 `input.type` 选择 `InputDriver` 或 `MockInputDriver`，真实依赖缺失时自动降级到 mock。

7. 修复技能指令契约
- 位置：`input/input_driver.py`
- 调整：`CommandType.SKILL` 同时支持 `skill_index` 和 `key_code`。
- 价值：兼容 `CombatLogic/BotFSM` 直接返回 `key_code` 的技能指令。

8. 修复 `tap("z")` 错误映射
- 位置：`input/input_driver.py`
- 调整：`x/z/c` 分别映射攻击/技能/跳跃，避免 `z` 被错误当作攻击。

9. 区分普通 STOP 与紧急 stop_all
- 位置：`input/input_driver.py`
- 调整：`STOP` 仅释放按键不关闭驱动；`stop_all` 仍保留紧急停机语义。

10. 收敛重复定义
- 位置：`logic/bot_fsm.py`、`ui/threads/engine_thread.py`
- 调整：`BotState` 统一复用 `core.types.BotState`；`EngineThread` 复用 `ui/threads/signals.py` 的 `EngineSignals`。

11. 修复 UI 线程配置与帧率控制
- 位置：`ui/threads/engine_thread.py`
- 调整：修复错误配置读取方式；帧率控制改为基于每帧真实耗时计算。
