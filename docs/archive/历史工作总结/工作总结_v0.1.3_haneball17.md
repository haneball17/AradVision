**技术要点**:
```python
# 透视变换公式
depth = (screen_y - horizon_y) * depth_scale
world_x = (screen_x - center_x) / (depth + 1)
world_y = depth

# Y 轴对齐判断
def is_aligned(obj1, obj2, tolerance=15.0) -> bool:
    error = abs(obj1.foot_point[1] - obj2.foot_point[1])
    return error <= tolerance
```

### 2. 主流程集成 (P0)

**文件**: `main.py` (287 → 415 行，+128 行)

**实现的数据流**:
```
CaptureEngine → MockYoloDetector → WorldModel → BotFSM → CombatLogic/PathPlanner → MockInputDriver
```

**核心功能**:
1. **模块初始化** (`initialize()` 方法):
   - ✅ 截图引擎 (CaptureEngine)
   - ✅ 检测器 (MockYoloDetector)
   - ✅ 世界模型 (WorldModel)
   - ✅ 状态机 (BotFSM)
   - ✅ 战斗逻辑 (CombatLogic)
   - ✅ 路径规划 (PathPlanner)
   - ✅ 输入驱动 (MockInputDriver)

2. **主循环逻辑** (`_main_loop()` 方法):
   ```python
   # 单帧处理流程
   1. 截取游戏画面 (frame = capture_engine.get_frame())
   2. 检测游戏对象 (detections = detector.detect(frame))
   3. 更新游戏上下文 (context = world_model.update(detections))
   4. 执行决策逻辑 (command = fsm.update(context))
   5. 发送输入指令 (input_driver.execute(command))
   ```

3. **状态驱动的决策逻辑**:
   - **COMBAT 状态** → 使用 CombatLogic 决定攻击/技能
   - **NAVIGATE 状态** → 使用 PathPlanner 规划路径
   - **PICKUP 状态** → 直接执行拾取指令
   - **STOP 状态** → 停止所有输入

4. **性能监控**:
   - 目标帧率: 30 FPS
   - 每 100 帧输出统计信息
   - 包括 FPS、FrameTime、CaptureLatency、Frames、State

5. **优雅关闭**:
   - 停止输入驱动
   - 停止截图引擎
   - 等待紧急停止线程结束
   - 输出统计信息
