# 文档归档说明

归档区用于保留可追溯历史，但不再把这些文档作为当前实现的事实来源。

## 目录约定

- `历史规划与规范/`
  - 早期需求、里程碑、协作方案、详细设计、编码规范等大而全文档。
- `历史诊断与阶段记录/`
  - 临时排障、阶段报告、一次性 UI 修复记录、环境诊断等。
- `历史工作总结/`
  - 旧版本总结和独立提交工作总结。
- `非主线专题/`
  - 当前不作为仓库默认主线维护的专题，例如训练数据工作台、时间线 UI 方案、YOLO 训练资料。

## 使用原则

- 需要了解当前仓库如何运行时，优先阅读 `docs/README.md` 中列出的主线文档。
- 需要追溯历史决策、旧方案或阶段性记录时，再进入归档区查阅。
- 归档文档默认不保证与当前代码完全一致，不应直接作为实现依据。
