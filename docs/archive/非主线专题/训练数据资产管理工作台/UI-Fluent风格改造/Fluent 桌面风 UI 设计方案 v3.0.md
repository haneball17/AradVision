# Fluent 桌面风 UI 设计方案 v3.0

目标：

* 轻
* 清爽
* 工具感
* 高效率
* 不花哨
* 不厚重

# 一、整体视觉定位

关键词：

* 极浅灰背景
* 软圆角
* 卡片浮层
* 低对比边界
* 单主色系统
* 行高舒适

---

# 二、整体布局结构（重构）

## 旧结构问题

* 模块堆叠感重
* 灰色块过多
* 时间线和筛选逻辑混合
* 分区线条明显

---

## 新结构建议

改为：

```text
┌────────────────────────────────────────────┐
│ 顶部导航栏                                 │
├──────────────┬─────────────────────────────┤
│ 主内容区      │ 右侧辅助区                  │
│（数据筛选）    │（连接 / 日志 / 预览）        │
├──────────────┴─────────────────────────────┤
│ 底部操作栏（导出 / 开始任务）               │
└────────────────────────────────────────────┘
```

---

# 三、视觉系统定义（Fluent 风格）

---

## 1️⃣ 背景系统

```text
App Background:   #F3F4F6
Surface:          #FFFFFF
Subtle Surface:   #F9FAFB
Divider:          #E5E7EB
```

重点：

* 不用中灰
* 不用深灰块
* 分区靠留白

---

## 2️⃣ 圆角系统

| 组件   | 圆角 |
| ------ | ---- |
| 主卡片 | 12px |
| 按钮   | 8px  |
| 输入框 | 6px  |
| 缩略图 | 8px  |

---

## 3️⃣ 阴影系统

卡片使用：

```text
0 1px 3px rgba(0,0,0,0.06)
```

Hover：

```text
0 4px 12px rgba(0,0,0,0.08)
```

---

# 四、模块级重设计

---

# 1️⃣ 顶部区域重设计

## 当前问题

* 标题厚重
* 黑条压视觉
* 工具感强

---

## 改为轻标题栏

```text
训练数据资产管理工作台
────────────────────────
[采集]  [筛选]  [预标注]
```

* 无黑条
* 主标题 18px
* 二级标签 14px
* 当前阶段下划线高亮

---

# 2️⃣ 数据筛选主区域（核心重构）

改为卡片容器：

```text
┌───────────────────────────┐
│ 样本筛选                   │
│ 搜索框 + 过滤器            │
│                           │
│ [ img ][ img ][ img ]     │
│ [ img ][ img ][ img ]     │
└───────────────────────────┘
```

---

## 缩略图设计（Fluent 版）

默认：

* 轻白卡片
* 无边框
* 8px 圆角
* 轻 hover 放大

选中：

* 2px 主色边框
* 轻阴影

状态：

| 状态 | 表现             |
| ---- | ---------------- |
| ⭐   | 右上角绿色小圆标 |
| ❌   | 透明度 0.4       |
| ⚠   | 橙色角标         |

---

# 3️⃣ 时间线改为轻量样式

旧时间线太工程。

新时间线：

* 高度 80px
* 背景透明
* 仅一条主轨道
* 已选区为主色

不要表格样式。

---

# 4️⃣ 右侧面板重设计

右侧区域采用：

* 白色卡片
* 分块间距 16px
* 每块轻标题

不要灰色大块。

---

# 5️⃣ 底部操作栏

底部固定操作条：

```text
[导出选中]    [开始预标注]
                                [开始任务]
```

主按钮：

* 绿色或蓝色
* 圆角 10px
* 高度 36px

---

# 五、间距系统（关键）

你现在最大问题是：

> 间距不足

统一规范：

* 页面 padding：24px
* 卡片内 padding：16px
* 控件间距：8px
* 模块间距：24px

---

# 六、字体层级

| 类型     | 字号 |
| -------- | ---- |
| 页面标题 | 20px |
| 模块标题 | 16px |
| 标签     | 13px |
| 辅助文字 | 12px |

全部字重 500–600 之间。

---

# 七、配色策略（收敛）

只用：

* 1 个主色
* 1 个成功色
* 1 个警告色
* 1 个危险色

不要出现多种蓝、绿混杂。

---

# 八、你现在 UI 和 Fluent 风差距总结

| 项目     | 你现在 | Fluent 风 |
| -------- | ------ | --------- |
| 灰度     | 偏重   | 极浅      |
| 卡片     | 不明显 | 明确      |
| 间距     | 偏紧   | 舒适      |
| 组件高度 | 不统一 | 完全统一  |
| 边框     | 明显   | 几乎无    |

---

# 九、视觉升级优先级

如果只做 6 个改动：

1. 改背景为极浅灰
2. 卡片白底 + 12px 圆角
3. 所有输入框统一高度 32px
4. 删除所有深灰分区块
5. 主按钮圆角加大
6. 增加 24px 页面 padding
