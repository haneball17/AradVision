# 训练数据资产管理工作台：导出与数据格式规范

**版本**：v2.2  
**日期**：2026-02-26  
**角色**：架构与逻辑工程师（yangmq17）

## 1. 目标
1. 将筛选结果稳定导出为可训练数据集。  
2. 防止数据泄漏（时间泄漏、场景泄漏、会话泄漏）。  
3. 输出可复现清单与校验报告。

## 2. 导出模式
1. `by_flag`：按 `star/review` 等标记导出。  
2. `by_filter`：按当前筛选表达式导出。  
3. `manual_selection`：按手动选中集合导出。

## 3. 导出目录冲突策略
默认策略：新建目录，不覆盖。
1. 目标目录不存在：直接创建。  
2. 目标目录已存在：自动追加后缀 `_v{n}`。  
3. 显式覆盖仅在 `overwrite=true` 时允许，并写审计记录。

## 4. 文件复制策略
默认优先硬链接，失败自动降级为复制：
1. `hardlink`：节省空间，速度快。  
2. `copy`：跨分区或链接失败时兜底。  
3. `symlink`：不作为默认，避免训练环境兼容问题。

## 5. 训练集拆分策略（防泄漏）
建议拆分：
1. `train: 0.8`  
2. `val: 0.15`  
3. `test: 0.05`

拆分原则：
1. 一级约束（最高优先级）：同一会话仅允许落在一个子集，降低时间相关泄漏。  
2. 二级约束：在一级约束满足后，再对场景与类别做近似分层。  
3. 三级约束：固定随机种子，保证可重复导出。  
4. 若一级约束与分层目标冲突，以一级约束为准，并在报告中记录偏差。

## 6. YOLO 导出格式
目录结构：
```text
dataset_xxx/
  images/
    train/
    val/
    test/
  labels/
    train/
    val/
    test/
  data.yaml
  selection_manifest.json
  validation_report.json
```

标签格式（每行）：
```text
<class_id> <x_center> <y_center> <width> <height>
```
坐标归一化区间必须在 `[0, 1]`。

## 7. `selection_manifest.json` 契约
说明：导出目录下的 `selection_manifest.json` 继承筛选阶段清单，并追加导出信息（`export_id/split/io_strategy/result`）。
```json
{
  "schema_version": "v2.2",
  "export_id": "export_20260226_150000",
  "created_at": "2026-02-26T15:00:00Z",
  "mode": "by_flag",
  "source_selection_id": "sel_20260226_130500",
  "source_sessions": ["ui_capture_20260226_120000_dnf_taiwan"],
  "range": {"start_ms": 1772088000000, "end_ms": 1772088600000, "inclusive": true},
  "filters": {"scene_in": ["combat"], "manual_flag_in": ["star", "review"]},
  "sampling": {
    "mode": "bucket_nearest",
    "frequency_sec": 1,
    "missing_bucket_policy": "skip",
    "tie_breaker": "timestamp_then_sample_id"
  },
  "split": {"train": 0.8, "val": 0.15, "test": 0.05, "seed": 42},
  "io_strategy": {"primary": "hardlink", "fallback": "copy"},
  "result": {"total": 960, "train": 768, "val": 144, "test": 48}
}
```

## 8. `validation_report.json` 契约
最低检查项：
1. 图像与标签文件配对完整率。  
2. 类别 id 合法性。  
3. 坐标范围合法性。  
4. bbox 宽高合法性。  
5. 子集分布与场景分布统计。

## 9. 导出事务与回滚
导出采用事务目录：
1. 先写入 `tmp_export_{id}`。  
2. 校验通过后原子重命名为正式目录。  
3. 失败时保留失败报告并清理临时文件（可配置保留）。

中断恢复：
1. 读取 `export_checkpoint.json`。  
2. 从未完成分片继续。  
3. 最终重新校验并补齐清单。

### 9.1 恢复检查点契约（`export_checkpoint.json`）
```json
{
  "schema_version": "v2.2",
  "export_id": "export_20260226_150000",
  "status": "running",
  "phase": "copy_labels",
  "last_processed_index": 580,
  "copied_images": 581,
  "copied_labels": 560,
  "failed_items": 3,
  "updated_at": "2026-02-26T15:05:00Z"
}
```
恢复规则：
1. 仅允许在 `status=running/failed` 恢复。  
2. 恢复时以 `last_processed_index` 之后的条目继续。  
3. 完成后写 `status=completed` 并归档检查点。

## 10. 资源与容量检查
导出前执行：
1. 目标磁盘可用空间估算。  
2. 预估导出体积。  
3. 空间不足时禁止开始导出并提示阈值。

## 11. 验收标准
1. 同一 `selection_manifest` 可在不同机器重建相同导出结果。  
2. 导出中断后可恢复或可回滚，不留下半成品污染。  
3. `validation_report` 无阻断级错误才允许进入训练阶段。
