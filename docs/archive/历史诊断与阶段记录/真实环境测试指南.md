## ⚠️ 常见问题

### 问题 1: numpy 未安装

**错误**:
```
ModuleNotFoundError: No module named 'numpy'
```

**解决**:
```powershell
pip install numpy
```

---

### 问题 2: loguru 未安装

**错误**:
```
ModuleNotFoundError: No module named 'loguru'
```

**解决**:
```powershell
pip install loguru
```

---

### 问题 3: FPS 不稳定

**可能原因**:
- 系统负载过高
- 截图性能问题
- 检测器性能问题

**解决**:
- 关闭其他应用程序
- 检查 CaptureLatency 是否过高
- 降低目标帧率（修改 `target_frame_time`）

---

### 问题 4: 状态机不切换

**可能原因**:
- MockYoloDetector 生成的数据不符合预期
- WorldModel 的分类逻辑有问题

**调试**:
```python
# 在 _main_loop 中添加
logger.info(f"检测类型: {[obj.cls_name for obj in detections]}")
logger.info(f"分类后: monsters={len(context.monsters)}, hero={context.hero is not None}")
```
