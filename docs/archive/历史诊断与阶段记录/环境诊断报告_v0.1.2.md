## 🔧 解决方案

### 方案 A：在有网络的环境中安装依赖（推荐）

在 Windows 开发环境或完整 Linux 环境中执行：

```bash
# 1. 创建虚拟环境
python3 -m venv .venv
source .venv/bin/activate  # Linux/Mac
# 或 .venv\Scripts\activate  # Windows

# 2. 安装依赖
pip install -r requirements.txt

# 3. 运行测试
pytest -v

# 4. 运行主程序
python main.py
```

### 方案 B：使用 Mock 验证逻辑层（当前环境）

由于决策层模块完全独立，可以先验证这部分：

```bash
# 测试决策层模块
python3 << 'EOF'
from logic.bot_fsm import BotFSM
from logic.combat import CombatLogic
from logic.path_planner import PathPlanner
from input.mock_driver import MockInputDriver

print("✓ 决策层模块导入成功")
print("✓ 可以进行逻辑验证测试")
EOF
```

### 方案 C：离线安装依赖

如果有可用的 wheel 文件或源码包：

```bash
# 下载依赖到本地
pip download -r requirements.txt -d ./packages

# 离线安装
pip install --no-index --find-links=./packages -r requirements.txt
```
