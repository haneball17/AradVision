# Windows 测试快速指南

## 🚀 快速开始（3 步）

### 步骤 1: 安装 PyQt5

打开 Windows 命令提示符（CMD）或 PowerShell：

```bash
pip install PyQt5
```

**验证安装**:
```bash
pip show PyQt5
```

应该看到版本信息（如 5.15.x）

---

### 步骤 2: 运行 UI

```bash
# 进入项目目录
cd AradVision

# 运行验证脚本
python scripts/verify_ui.py
```

**或者直接运行**:
```bash
python scripts/test_pyqt_ui.py
```

---

### 步骤 3: 按测试清单测试

窗口打开后，按照 **`docs/测试记录模板.md`** 中的清单逐项测试。

## ❓ 常见问题

### Q1: 提示 "No module named 'PyQt5'"

**A**: 未安装 PyQt5，执行：
```bash
pip install PyQt5
```

---

### Q2: 窗口打开但显示空白

**A**: 高 DPI 缩放问题，尝试：
1. 右键脚本 → 属性 → 兼容性 → 高 DPI 设置
2. 或在 Windows 显示设置中使用 100% 缩放

---

### Q3: 点击按钮无响应

**A**: 正常现象，部分功能未实现：
- ✅ UI 响应（弹出提示框）= 正常
- ❌ 点击无任何反应 = 问题
