# PyQt5 UI 测试指南

## 测试概述

本文档提供 AradVision PyQt5 控制面板的完整测试指南，分为三个阶段逐步推进。

**测试原则**：由简入繁，逐步验证
- **阶段 1**: UI 基础功能（无依赖，立即可测）
- **阶段 2**: Mock 模式（模拟数据，无需游戏）
- **阶段 3**: 真实模式（需要游戏环境）

---

## 阶段 1: UI 基础功能测试

### 目标
验证 UI 界面是否正常显示和响应，无需任何依赖。

### 环境要求
- Windows 10/11
- Python 3.10+
- PyQt5

### 准备步骤

```bash
# 1. 克隆或更新代码
cd AradVision
git pull origin dev

# 2. 安装 PyQt5
pip install PyQt5

# 或者安装完整依赖
pip install -r requirements.txt
```

### 测试步骤

#### 1.1 启动测试
```bash
python scripts/test_pyqt_ui.py
```

**预期结果**:
- ✅ 窗口正常打开

**如果失败**:
- 检查 PyQt5 是否安装：`pip show PyQt5`

## 阶段 2: Mock 模式测试

### 环境要求
- 阶段 1 所有要求
- 项目核心模块（无需 YOLO 模型）

### 准备步骤

```bash
# 1. 确保所有核心模块可用
python -c "from core.capture import create_capture_engine; from vision.mock_detector import MockYoloDetector; print('✓ 核心模块可用')"

# 2. 启动 Mock 模式
python scripts/test_pyqt_ui.py --mock
```

**注意**: 当前 `test_pyqt_ui.py` 不支持命令行参数，需要修改。

### 修改启动脚本

在 `scripts/test_pyqt_ui.py` 中添加：

```python
import argparse

parser = argparse.ArgumentParser()
parser.add_argument('--mock', action='store_true', help='使用 Mock 模式')
args = parser.parse_args()

# 创建主窗口时传入模式
window = UIWindow(use_mock=args.mock)  # 需要修改 MainWindow 支持此参数
```

## 常见问题排查

### 问题 1: ImportError: No module named 'PyQt5'

**解决**:
```bash
pip install PyQt5
```

### 问题 2: 窗口显示一片空白

**原因**: 高 DPI 缩放问题

**解决**:
- 确保启动脚本中启用了高 DPI 缩放
- 或在 Windows 显示设置中调整缩放比例

### 问题 3: 按钮点击无响应

**原因**: 功能未实现或信号未连接

**解决**:
- 检查日志面板是否有错误信息
- 参考文档查看该功能是否已实现

### 问题 4: 视频预览黑屏

**原因**: 系统未启动或数据流未连接

**解决**:
- 点击"启动系统"按钮
- 检查是否连接到游戏窗口（真实模式）
- 检查日志中是否有错误信息
