## 核心收口结论

1. 当前 YOLO 的定位仍然是固定路线 MVP 的局部辅助感知，不是通用决策主链路
2. 训练顺序建议按 `hero -> hero + gate -> hero + gate + item` 分阶段推进
3. `hero` 用于站位、卡住判定和边缘工作区判断
4. `gate` 用于目标方向局部门确认，不决定路线方向
5. `item` 只用于清房后脚底局部拾取判断，不扩展成整屏拾取主线
6. 清房后拾取默认采用“局部检测 + 有限次 `X` + 每次按键后复检 + 超预算继续主线”的口径
