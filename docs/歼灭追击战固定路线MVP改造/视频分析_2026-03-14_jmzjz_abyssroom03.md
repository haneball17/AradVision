## 1. 当前已知环境

用户提供环境如下：


当前判断：

2. `DPI 150%` 是高风险项，后续 `WGC/MSS` 与 UI ROI 需要特别留意窗口边框和裁剪偏移。
3. 这段视频是完整流程素材，不是单房间片段。

## 4. 边界精化结果

基于补充时间点截图，当前可以把两个关键边界进一步收窄：

### 4.1 `transition` 边界

当前视频里的首个入场 `transition` 可细化为：

| 时间点 | 当前判断 |
| --- | --- |
| `00:11.0 - 00:15.5` | 加载插画界面 |
| `00:16.0` | 黑屏/切场瞬间 |
| `00:16.5` | 刚进入副本，画面仍较暗 |
| `00:17.0` | 首个可操作帧 |
| `00:18.0` | 已进入稳定战斗/副本态 |

结论：

1. `transition` 不应只靠“整体偏暗”判断。
2. 当前默认 `transition_roi` 明显没有覆盖到最稳定的加载/黑屏信号。

### 4.2 `run_finished` 边界

当前视频里的结算过程可细化为：

| 时间点 | 当前判断 |
| --- | --- |
| `04:40 - 04:50` | 仍在副本内，接近结束阶段 |
| `04:52` | 结算覆盖层开始出现 |
| `04:54 - 04:58` | 结算面板展开过程 |
| `05:00` | 稳定结算界面 |
| `05:02 - 05:04` | 结算界面持续 |

结论：

1. `run_finished` 应优先瞄准结算面板主文字和评分区域。
2. 当前默认 `finish_roi` 完全没有覆盖到这些信号。

## 5. 当前可观察到的状态信号

### 4.1 `MainViewReader`

当前视频已经能支持第一轮复核的状态：

1. 城镇/准备区：不是当前 Reader 目标状态，但可作为“非副本态”对照组。
2. 加载画面：可作为 `transition` 候选样本。
3. 副本战斗中：`combat_room` 候选样本充足。
4. 结算界面：`run_finished` 候选样本明确。

当前仍需二次截图才能稳定确认的状态：

1. `clear_room`
2. `boss_room`
3. 过图瞬间和过图结束瞬间的边界帧

### 4.2 `MinimapReader`

当前视频能看出小地图区域持续存在，但仅靠第一轮抽样还不能把以下变化稳定定性：

1. 邻接房变暗
2. 邻接房变亮/问号闪烁
3. Boss 提示
4. 深渊特殊房提示

结论：

`MinimapReader` 下一步必须依赖“按时间点截图”，不能只靠粗采样帧。

### 4.3 `StateReader`

当前粗采样能看出：

1. 血条、蓝条、技能栏、物品栏都在固定位置
2. 结算前后 UI 结构明显不同

当前还不能确认：

1. 背包重量条是否在这段视频里出现过高负载信号
2. 空格数是否能从现有 HUD 稳定读出
3. 药水可用/冷却状态是否足够稳定
4. 商店/维修界面在这段视频中是否完整出现

## 7. 截图导出要求

1. 必须从原视频直接导出原始分辨率帧，不要二次压缩。
2. 仓库已提供第二轮截图时间点清单：

`docs/歼灭追击战固定路线MVP改造/jmzjz_abyssroom03_第二轮截图时间点.txt`

3. 可直接使用仓库脚本批量导出：

```bash
python3 scripts/extract_video_frames.py \
  --video /mnt/e/code/AradVision/assets/video/jmzjz_abyssroom03.mp4 \
  --times-file /mnt/e/code/AradVision/docs/歼灭追击战固定路线MVP改造/jmzjz_abyssroom03_第二轮截图时间点.txt \
  --output /mnt/e/code/AradVision/assets/video/jmzjz_abyssroom03_frames \
  --prefix jmzjz_abyssroom03
```

4. 文件名按下面格式：

```text
jmzjz_abyssroom03_<mm-ss>_<scene>.png
```

示例：

```text
jmzjz_abyssroom03_00-12_transition.png
jmzjz_abyssroom03_00-30_combat.png
jmzjz_abyssroom03_05-00_result.png
```

5. 如果你发现某个时间点附近 1 到 2 秒内画面变化很快，可以多导出前后各 2 帧。
